## 一、新增 equipment 引用与扫描状态变量

文件：

```text
game/assets/script/main.gd
```

### 1. 获取 equipment 节点

新增代码：

```gdscript
@onready var equipment: Node3D = $rover/equipment
```

解释：

- `$rover/equipment` 表示从 `trail_camera.tscn` 的根节点出发，找到：

```text
rover
└── equipment
```

- `@onready` 表示节点树准备完成后再赋值，避免路径还没建立时访问失败。
- 变量类型声明为 `Node3D`，因为动画需要修改它的 `rotation` 属性。

### 2. 记录扫描目标

新增代码：

```gdscript
var scanning_rock: Node3D = null
```

解释：

- `null` 表示当前没有正在扫描的石头。
- 点击 `Research` 后，会把 `current_rock` 存入 `scanning_rock`。
- 动画结束时根据 `scanning_rock` 判断应该研究哪块石头。

作用：

```text
防止扫描过程中目标丢失后，误研究其他石头。
防止同一块石头被重复研究。
```

### 3. 保存 Tween 动画对象

新增代码：

```gdscript
var scan_tween: Tween
```

解释：

- `Tween` 是 Godot 的补间动画对象。
- 保存它是为了在启动新动画前可以判断并停止旧动画。

例如：

```gdscript
if scan_tween != null and scan_tween.is_valid():
	scan_tween.kill()
```

这样可以避免多个 Tween 同时控制 `equipment.rotation`。

### 4. 保存 equipment 原始旋转

新增代码：

```gdscript
var equipment_rest_rotation: Vector3
```

在 `_ready()` 中初始化：

```gdscript
equipment_rest_rotation = equipment.rotation
```

解释：

- `equipment_rest_rotation` 是 equipment 的基础角度。
- 扫描动画会临时向下倾斜。
- 动画结束后必须回到这个记录值，而不是简单回到 `Vector3.ZERO`。

好处：

```text
如果以后你在场景中手动调整了 equipment 的默认角度，
脚本仍然会恢复到调整后的角度，而不是强制归零。
```

## 二、新增可调扫描参数

新增代码：

```gdscript
@export_range(0.0, 90.0, 0.1) var scan_tilt_degrees: float = 22.0
@export_range(0.05, 2.0, 0.01) var scan_tilt_duration: float = 0.3
@export_range(0.1, 5.0, 0.01) var scan_hold_duration: float = 1.5
@export_range(0.05, 2.0, 0.01) var scan_return_duration: float = 0.4
```

### 参数解释

```text
scan_tilt_degrees
```

扫描时向下倾斜的角度，默认 `22°`。

```text
scan_tilt_duration
```

从原始角度倾斜到扫描角度所需时间，默认 `0.3` 秒。

```text
scan_hold_duration
```

保持倾斜扫描状态的时间，默认 `1.5` 秒。

```text
scan_return_duration
```

从扫描角度恢复到原始角度的时间，默认 `0.4` 秒。

### 总扫描时长

```text
0.3 + 1.5 + 0.4 = 2.2 秒
```

### `@export_range` 的作用

这些变量会显示在 Inspector 中，并限制可输入范围。

例如：

```gdscript
@export_range(0.0, 90.0, 0.1)
```

表示：

```text
最小值 = 0.0
最大值 = 90.0
步长 = 0.1
```

你可以在 Godot 编辑器中直接调整，不需要修改脚本。

## 三、research UI 状态增强

### 1. 扫描期间禁用 Research 按钮

新增代码：

```gdscript
research_button_do.disabled = scanning_rock != null
```

解释：

- `scanning_rock != null` 表示正在扫描。
- 扫描期间 `Research` 按钮会被禁用。
- 动画完成后 `scanning_rock` 变回 `null`，按钮恢复可用。

作用：

```text
防止扫描未结束时重复点击按钮。
```

### 2. 恢复未研究提示文本

新增代码：

```gdscript
label_do.text = research_prompt
```

位置：

```gdscript
if current_rock.researched:
	label_do.text = "doing the research, blablabla"
else:
	label_do.text = research_prompt
```

解释：

- 如果当前石头已研究，显示已研究提示。

## 四、点击 Research 后启动扫描流程

新增代码：

```gdscript
func button_do_clicked():
	if current_rock == null or current_rock.researched or scanning_rock != null or not research_ui.visible:
		return
	scanning_rock = current_rock
	research_button_do.disabled = true
	label_do.text = "Scanning rock..."
	start_equipment_scan_animation()
```

### 判断条件解释

```gdscript
if current_rock == null
```

当前没有可研究的石头。

```gdscript
or current_rock.researched
```

当前石头已经研究过。

```gdscript
or scanning_rock != null
```

当前已经在扫描另一块石头。

```gdscript
or not research_ui.visible
```

research UI 没有显示，不允许绕过 UI 触发研究。

满足任意一个条件时直接 `return`。

### 通过检查后

```gdscript
scanning_rock = current_rock
```

锁定当前要扫描的石头。

```gdscript
research_button_do.disabled = true
```

禁用按钮，防止重复点击。

```gdscript
label_do.text = "Scanning rock..."
```

显示扫描中状态。

```gdscript
start_equipment_scan_animation()
```

启动 equipment 倾斜动画。

### 与原逻辑的区别

原逻辑是点击按钮后立即执行：

```gdscript
current_rock.researched = true
tech_point += 5
```

新逻辑是：

```text
点击按钮
→ 锁定扫描目标
→ 播放动画
→ 动画结束
→ 标记 researched
→ tech_point +5
```

因此 research 过程更有反馈感。

## 五、equipment 向下倾斜动画代码

新增代码：

```gdscript
func start_equipment_scan_animation() -> void:
	if scan_tween != null and scan_tween.is_valid():
		scan_tween.kill()
	equipment.rotation = equipment_rest_rotation
	scan_tween = create_tween()

	var tilted_rotation := equipment_rest_rotation + Vector3(deg_to_rad(scan_tilt_degrees), 0, 0)

	scan_tween.tween_property(
		equipment,
		"rotation:x",
		tilted_rotation.x,
		scan_tilt_duration
	).set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_OUT)

	scan_tween.tween_interval(scan_hold_duration)

	scan_tween.tween_property(
		equipment,
		"rotation:x",
		equipment_rest_rotation.x,
		scan_return_duration
	).set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_IN_OUT)

	scan_tween.finished.connect(_on_equipment_scan_finished)
```

### 1. 停止旧动画

```gdscript
if scan_tween != null and scan_tween.is_valid():
	scan_tween.kill()
```

解释：

- 如果之前已经有扫描动画还在运行，先停止它。
- 防止两个 Tween 同时修改同一个 `rotation:x`。

### 2. 重置初始角度

```gdscript
equipment.rotation = equipment_rest_rotation
```

解释：

- 新动画开始前，把 equipment 放回基础角度。
- 保证每次动画都从确定的初始状态开始。

### 3. 创建新的 Tween

```gdscript
scan_tween = create_tween()
```

解释：

- 在当前 `main.gd` 节点上创建一个补间动画。
- 该节点在场景存活期间不会消失，适合管理扫描动画。

### 4. 计算向下倾斜角度

```gdscript
var tilted_rotation := equipment_rest_rotation + Vector3(deg_to_rad(scan_tilt_degrees), 0, 0)
```

解释：

- `scan_tilt_degrees` 是角度值。
- Godot 的 `rotation` 使用弧度。
- `deg_to_rad()` 把角度转换成弧度。
- 只修改 X 轴，让 equipment 向下倾斜。

当前粒子的发射方向是 equipment 的局部 `+Z`。绕本地 X 轴正向旋转后，`+Z` 方向会向下偏转，形成扫描岩石的效果。

### 5. 向下倾斜动画

```gdscript
scan_tween.tween_property(
	equipment,
	"rotation:x",
	tilted_rotation.x,
	scan_tilt_duration
).set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_OUT)
```

解释：

- 动画对象：`equipment`
- 动画属性：`rotation:x`
- 目标值：`tilted_rotation.x`
- 持续时间：`scan_tilt_duration`
- 缓动方式：`Sine`
- Ease：`EaseOut`

视觉效果：

```text
开始较快，接近目标角度时逐渐减慢。
```

### 6. 保持扫描状态

```gdscript
scan_tween.tween_interval(scan_hold_duration)
```

解释：

- Tween 在这段时间内不改变 equipment 角度。
- 粒子保持向下扫描状态。
- 默认保持 `1.5` 秒。

### 7. 恢复原始角度

```gdscript
scan_tween.tween_property(
	equipment,
	"rotation:x",
	equipment_rest_rotation.x,
	scan_return_duration
).set_trans(Tween.TRANS_SINE).set_ease(Tween.EASE_IN_OUT)
```

解释：

- 把 X 轴旋转恢复到 `equipment_rest_rotation.x`。
- 使用 `EaseInOut`，恢复过程更自然。
- 不会影响 Y 轴和 Z 轴。

### 8. 动画结束后回调

```gdscript
scan_tween.finished.connect(_on_equipment_scan_finished)
```

解释：

- Tween 完整执行完后调用 `_on_equipment_scan_finished()`。
- 研究结算在这个回调中完成。

## 六、扫描完成后的研究结算代码

新增代码：

```gdscript
func _on_equipment_scan_finished() -> void:
	var scanned_rock := scanning_rock
	scanning_rock = null

	if scanned_rock != null and not scanned_rock.researched:
		scanned_rock.researched = true
		tech_point += 5
		print(tech_point)

	if current_rock != null:
		show_current_research()
	elif current_rock == null:
		button_exist_clicked()
```

### 1. 临时保存扫描目标

```gdscript
var scanned_rock := scanning_rock
scanning_rock = null
```

解释：

- 先把正在扫描的石头保存到局部变量。
- 马上清空 `scanning_rock`，表示扫描状态结束。
- 后续结算使用 `scanned_rock`，保证处理的仍然是动画开始时锁定的目标。

### 2. 标记石头已研究

```gdscript
if scanned_rock != null and not scanned_rock.researched:
	scanned_rock.researched = true
```

解释：

- 只有扫描目标存在且未研究过才修改状态。
- 双重检查避免重复研究。

### 3. 增加科技点

```gdscript
tech_point += 5
print(tech_point)
```

解释：

- 每完成一次扫描研究，科技点增加 `5`。
- `print()` 用于调试输出当前科技点。

### 4. 刷新 UI

```gdscript
if current_rock != null:
	show_current_research()
elif current_rock == null:
	button_exist_clicked()
```

解释：

如果当前仍在某个石头检测范围内：

```text
刷新 research UI
恢复按钮状态
显示已研究提示
```

如果已经离开所有石头范围：

```text
隐藏 research UI
恢复鼠标捕获模式
```

## 九、扫描粒子长度相关参数

文件：

```text
game/assets/scene/equipment.tscn
```

节点：

```text
equipment/GPUParticles3D
```

新增参数：

```gdscript
amount = 20
lifetime = 2.5
preprocess = 2.5
```

### 1. `amount = 20`

原值：

```text
8
```

解释：

- 增加同时存在的粒子数量。
- 与新的 `lifetime` 配合后，粒子发射密度仍保持约 `8 个/秒`。

计算：

```text
修改前：8 / 1.0 = 8 个/秒
修改后：20 / 2.5 = 8 个/秒
```

因此轨迹变长但不会明显变稀疏。

### 2. `lifetime = 2.5`

原值：

```text
1.0
```

解释：

- 粒子存活时间变成原来的 `2.5` 倍。
- 初速度仍为 `1.0`，关闭重力后近似匀速直线运动。
- 粒子轨迹长度从：

```text
1.0 × 1.0 = 1.0
```

变为：

```text
1.0 × 2.5 = 2.5
```

### 3. `preprocess = 2.5`

原默认值：

```text
0
```

解释：

- 场景启动时先预模拟 `2.5` 秒粒子。
- 游戏一开始就能看到完整长度的扫描轨迹。
- 不需要等待粒子逐渐发射填满路径。
