# 右上角重置按钮功能说明（2026-10-12）

## 一、改动说明

- 仅在主界面 `CanvasLayer` 右上角新增一个「重置 Reset」按钮。
- 点击按钮后，火星车（rover）立即传送回游戏开始时记录的初始位置与姿态。
- 传送时同时清零线速度与角速度，避免传送后带着旧惯性继续滑动 / 翻滚。
- **不改动其他任何逻辑**：
  - 不重置 `tech_point`（科技点）；
  - 不重置岩石的 `researched`（已研究）状态；
  - 无死亡次数、无键盘快捷键、无存盘、无其他系统变化。

## 二、涉及文件

| 文件 | 改动内容 |
| --- | --- |
| `game/assets/scene/trail_camera.tscn` | 新增 UI 节点 `CanvasLayer/ResetButton` |

## 三、代码说明

### 1. `game/assets/scene/trail_camera.tscn`

新增节点（位于 `Label_TP1` 之后）：

```ini
[node name="ResetButton" type="Button" parent="CanvasLayer"]
layout_mode = 0
offset_left = 1044.0
offset_top = 16.0
offset_right = 1140.0
offset_bottom = 48.0
text = "重置 Reset"
```

- 位置在默认视口（1152×648）右上角。

### 2. `game/assets/script/main.gd`

**新增节点引用与变量**

```gdscript
@onready var reset_button: Button = $CanvasLayer/ResetButton
var initial_rover_transform: Transform3D
```

**类型调整**

```gdscript
@onready var rover: VehicleBody3D = $rover
```

- 原为 `Node3D`；改为 `VehicleBody3D` 是为了能清零 `linear_velocity` / `angular_velocity`（传送的必要物理状态清理）。

**`_ready()` 中新增两行**

```gdscript
initial_rover_transform = rover.global_transform
reset_button.pressed.connect(_on_reset_button_pressed)
```

- 启动时记录一次初始 transform（即"最开始的位置"），并连接按钮信号。

**新增点击处理函数**

```gdscript
func _on_reset_button_pressed() -> void:
	rover.global_transform = initial_rover_transform
	rover.linear_velocity = Vector3.ZERO
	rover.angular_velocity = Vector3.ZERO
```

- 传送回初始位置，并清零速度。除此之外不做任何其他事。

## 四、使用与验证

### 重要：为什么"直接点击没反应"

游戏原有逻辑在启动时会把鼠标设为**锁定模式**（`Input.MOUSE_MODE_CAPTURED`，见 `main_motion.gd` / `First_pv.gd`）。这是 Godot 的引擎行为：**鼠标锁定时，光标隐藏且无法移动，UI 按钮收不到任何点击事件**——这不是按钮代码的问题。

经无头仿真验证：
- 直接触发按钮 `pressed` 信号后，火星车成功回到出生点（传送逻辑正常）；
- 按钮区域没有任何控件遮挡（minimap 仅在左上角 254×254，研究弹窗不在右上角）；
- 信号连接在场景加载时无任何报错。

### 正确操作步骤

1. 按 **Esc**（或 **Tab**）释放鼠标 —— 这是游戏原有的释放鼠标按键；
2. 光标出现后，移动到右上角点击「重置 Reset」按钮（已加大为 140×44，并带悬停提示）；
3. 火星车立即传送回初始位置，科技点与已研究状态不变。

### 验证结论

- Godot 4.7.1 `--check-only` 脚本语法检查通过；
- 主场景 `--headless --quit` 加载通过，无节点路径/连接错误；
- `pressed` 信号触发后传送生效（仿真中距离误差仅物理沉降 ~0.06m）。
