# equipment 前方检测与黑屏水平视角过场调整说明

记录时间：

```text
2026-10-10 16:46:48
```

本次调整包含两个核心重写：

1. research 检测不再使用岩石自身的大范围球形区域，而是改为 equipment 正前方约 `1m` 的专用检测区域。
2. 点击 `Research` 后的动画改为完整镜头过场：

```text
黑屏
→ 切入水平视角摄像头
→ 淡出黑屏并观察 equipment 扫描动画
→ 淡入黑屏
→ 切回原游戏摄像头
→ 淡出黑屏并退出过场
```

涉及文件：

```text
game/assets/scene/equipment.tscn
game/assets/scene/sojourner.tscn
game/assets/script/main.gd
game/assets/scene/trail_camera.tscn
```

## 一、equipment 正前方检测区域

### 1. 新节点结构

`equipment.tscn` 中新增：

```text
equipment
├── Cylinder
├── GPUParticles3D
└── EquipmentDetectionArea
    └── ForwardCollisionShape3D
```

其中：

```text
EquipmentDetectionArea
```

是专用 `Area3D`，用于检测 equipment 前方的岩石 `StaticBody3D`。

```text
ForwardCollisionShape3D
```

是检测区域的具体 `BoxShape3D`。

### 2. 区域尺寸

本地 `BoxShape3D` 尺寸：

```text
size = Vector3(5.0, 5.0, 6.6666667)
```

`equipment` 实例在 `sojourner.tscn` 中的缩放为：

```text
0.15
```

因此最终世界空间尺寸为：

```text
X = 5.0 × 0.15 = 0.75m
Y = 5.0 × 0.15 = 0.75m
Z = 6.6666667 × 0.15 = 1.0m
```

也就是检测区约为：

```text
宽 0.75m
高 0.75m
长 1.0m
```

### 3. 区域位置

`ForwardCollisionShape3D` 的本地 Z 偏移为：

```text
4.4462967
```

乘以 equipment 的 `0.15` 缩放后，中心距离 equipment 根节点约：

```text
0.667m
```

检测盒长度为 `1.0m`，因此它的 Z 范围约为：

```text
0.167m → 1.167m
```

equipment 模型前端大约在本地 Z `0.167m` 处，所以实际检测范围是：

```text
equipment 正前方 0m → 1m
```

这保证只有位于 equipment 前方约 `1m` 内的岩石才会触发 research UI。

### 4. 检测方向

检测区是 equipment 的子节点，因此它跟随 equipment 的朝向：

```text
equipment 本地 +Z
```

车辆转向时，检测区也会跟着转向。只有岩石进入 equipment 正前方区域，才会成为 `current_rock`。

### 5. 检测信号连接

`trail_camera.tscn` 中新增节点信号连接：

```text
rover/equipment/EquipmentDetectionArea.body_entered
→ Node3D._on_equipment_detection_body_entered

rover/equipment/EquipmentDetectionArea.body_exited
→ Node3D._on_equipment_detection_body_exited
```

也就是说，`main.gd` 不再遍历每块岩石自己的 `area3d` 并检测车辆是否进入岩石范围，而是由 equipment 前方专用区域检测岩石。

旧岩石区域仍保留在 `rock1.tscn` 中，但不再作为 `main.gd` 的 research 触发来源。

## 二、main.gd 检测逻辑重写

文件：

```text
game/assets/script/main.gd
```

### 1. 从岩石 StaticBody 找到岩石根节点

新增函数：

```gdscript
func _get_rock_from_detection_body(body: Node3D) -> Node3D:
	var rock := body.get_parent() as Node3D
	if rock != null and rock.get("researched") != null:
		return rock
	return null
```

解释：

- `EquipmentDetectionArea.body_entered` 收到的是岩石场景里的 `StaticBody3D`。
- 该 `StaticBody3D` 的父节点才是拥有 `researched` 属性的岩石根节点。
- 通过 `rock.get("researched") != null` 确认当前检测到的是可研究对象。
- 非岩石碰撞体不会被加入 research 状态。

### 2. 进入检测区

```gdscript
func _on_equipment_detection_body_entered(body: Node3D) -> void:
	if scanning_rock != null:
		return

	var rock := _get_rock_from_detection_body(body)
	if rock == null:
		return

	if not nearby_rocks.has(rock):
		nearby_rocks.append(rock)

	current_rock = rock
	show_current_research()
```

效果：

```text
岩石进入 equipment 正前方 1m 区域
→ 记录为 nearby_rocks
→ 设为 current_rock
→ 显示 research UI
```

扫描过程中会忽略新的进入事件，避免过场期间目标被其他岩石抢占。

### 3. 离开检测区

```gdscript
func _on_equipment_detection_body_exited(body: Node3D) -> void:
	var rock := _get_rock_from_detection_body(body)
	if rock == null:
		return

	nearby_rocks.erase(rock)
	if current_rock == rock:
		current_rock = null
		if not nearby_rocks.is_empty():
			current_rock = nearby_rocks.back()
			show_current_research()
		elif scanning_rock == null:
			button_exist_clicked()
```

效果：

- 岩石离开 equipment 前方区域后，从候选列表移除。
- 如果还有其他岩石也在 equipment 前方区域内，则切换到该岩石。
- 如果没有候选岩石且当前不在扫描中，则关闭 UI。
- 如果当前正在扫描，则不强行关闭，过场动画会继续完成。

### 1. 新增节点

文件：

```text
game/assets/scene/sojourner.tscn
```

新增：

```text
VehicleBody3D
└── ScanCutsceneCamera
```

### 2. 摄像头位置

本地位置：

```text
Position = (1.4, 0.19072092, 0.7517834)
```

equipment 在 `sojourner.tscn` 中的位置接近：

```text
(-0.08286, 0.19072, 0.75178)
```

因此 `ScanCutsceneCamera` 与 equipment 处在几乎相同的 Y/Z 平面上，并位于 equipment 右侧约 `1.4m` 处。

### 3. 摄像头方向

摄像头朝向车辆与 equipment 的 `-X` 方向，从侧面水平观察 equipment。

验证结果：

```text
scan_camera_horizontal=true
```

也就是摄像头没有俯视或仰视，符合“水平视角摄像头观察动画”的要求。

### 4. 摄像头参数

```text
Current = false
FOV = 65
```

平时不启用，只在过场动画中通过方法轨道切换为当前摄像头。

## 四、新的黑屏-水平视角-黑屏过场

### 1. 主控动画节点

`trail_camera.tscn` 根节点下新增：

```text
Node3D
└── ResearchCutsceneAnimationPlayer
```

动画名：

```text
research_cutscene
```

动画长度：

```text
3.2 秒
```

本版移除了 equipment 内部单独的 `ScanAnimationPlayer`，改由主场景中的 `ResearchCutsceneAnimationPlayer` 统一控制：

```text
黑屏淡入淡出
摄像头切换
equipment 倾斜与恢复
粒子开启与关闭
研究进度条
动画完成信号
```

这样所有过场时间轴集中在一个 `AnimationPlayer` 中，更容易保证节奏同步。

### 2. 过场 UI 节点

```text
CanvasLayer
└── research_cutscene
    ├── Dim
    ├── CutsceneLabel
    └── ScanProgress
```

`Dim` 是全屏黑色 `ColorRect`，用于黑屏转场。

`CutsceneLabel` 显示：

```text
Analyzing rock sample...
```

`ScanProgress` 是研究进度条。

## 五、完整动画时间轴

动画总时长：

```text

```

### 1. 第一段黑屏

```text

```

状态：

```text

```

此时仍使用原游戏摄像头，但玩家看不到画面。

```text

```

因为切换发生在黑屏期间，玩家不会看到镜头跳变。

### 3. 黑屏淡出，进入观察画面

```text
0.3 → 0.5 秒
```

```text

```

```text

```

```text
equipment rotation.x: 0° → 22°
```

### 5. 到达角度后开启粒子

在：

```text
0.92 秒
```

```text

```


```gdscript

```

由于 `0.92` 秒已经晚于 `0.9` 秒到达 `22°` 的时间点，粒子只会在 equipment 已经到达扫描角度后出现。

```text

```

```text

GPUParticles3D.emitting = false
```

```text
2.3 → 2.6 秒
```

状态：

```text

```

### 8. 第二段黑屏

```text
2.7 → 2.9 秒
```

状态：

```text
Dim alpha 0.0 → 1.0
```

### 9. 切回原游戏摄像头

在：

```text
2.9 秒
```


切换同样发生在黑屏期间，因此不会看到镜头突兀跳变。

## 六、车辆锁定与动画继续播放

点击 `Research` 后：

```gdscript
rover.process_mode = Node.PROCESS_MODE_DISABLED
```

效果：

```text
车辆控制停止
VehicleBody3D 物理处理停止
普通驾驶输入停止
```

但以下节点仍能继续工作：

```text
ResearchCutsceneAnimationPlayer
GPUParticles3D
```

原因：

- `ResearchCutsceneAnimationPlayer` 是 `trail_camera` 根节点的子节点，不在 disabled 的 rover 子树下。
- `GPUParticles3D` 设置为：

```text
Process Mode = Always
```

因此黑屏、摄像头切换、equipment 动画和扫描粒子都能在过场期间继续播放。

动画结束后：

```gdscript
rover.process_mode = rover_process_mode_before_cutscene
```

车辆恢复正常控制。

| 项目 | 上一版 | 本版 |

| 检测来源 | 岩石 Area3D 检测车辆 | equipment 前方 Area3D 检测岩石 |

| 总时长 | 2.2 秒 | 3.2 秒 |

## 八、Godot 编辑器中如何调整

### 1. 调整检测距离

打开：

```text
assets/scene/equipment.tscn
```

选择：

```text
EquipmentDetectionArea/ForwardCollisionShape3D
```

修改：

```text
Shape Size.Z
```

当前本地长度：

```text
6.6666667
```

由于最终世界缩放是 `0.15`：

```text
本地 Z 长度 ÷ 0.6666667 ≈ 世界米数
```

例如想改成前方 `1.2m`：

```text
1.2 ÷ 0.15 = 8.0
```

可将 Shape Size.Z 改为：

```text
8.0
```

同时建议调整 Z Position，使盒体从 equipment 前端开始。

### 2. 调整水平摄像头

打开：

```text
assets/scene/sojourner.tscn
```

选择：

```text
VehicleBody3D/ScanCutsceneCamera
```

可直接调整：

```text
Position
Rotation
FOV
```

保持 Y 轴接近水平即可维持水平视角。

### 3. 调整黑屏节奏

打开：

```text
assets/scene/trail_camera.tscn
```

选择：

```text
ResearchCutsceneAnimationPlayer
```

动画：

```text
research_cutscene
```

`Dim:color:a` 轨道控制黑屏淡入淡出。

当前关键时间：

```text
0.0 黑屏
0.3 → 0.5 淡出
2.7 → 2.9 淡入
3.1 → 3.2 淡出
```

### 4. 调整扫描角度和粒子触发

同一动画中：

```text
rover/equipment:rotation:x
```

控制 equipment 倾斜。

当前：

```text
0.6 → 0.9 秒：0° → 22°
0.9 → 2.3 秒：保持 22°
2.3 → 2.6 秒：22° → 0°
```

粒子轨道：

```text
rover/equipment/GPUParticles3D:visible
rover/equipment/GPUParticles3D:emitting
```

当前触发点：

```text
0.92 秒
```

如果修改了到达角度的时间，应保证粒子触发时间大于角度到达时间。
