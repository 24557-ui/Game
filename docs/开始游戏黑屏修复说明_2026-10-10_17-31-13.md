# 开始游戏黑屏修复说明

记录时间：

```text
2026-10-10 17:31:13
```

## 问题现象

启动 `trail_camera.tscn` 后，游戏一开始就是黑屏。

此时不是渲染场景缺失，也不是主摄像头没有生效，而是 research 过场的全屏黑色遮罩在启动阶段被显示了出来。

---

## 修改文件

```text
game/assets/scene/trail_camera.tscn
```

没有修改 `main.gd`，没有修改摄像头，也没有修改 Terrain 或环境设置。

---

## 原因分析

### 1. 过场节点启动状态不正确

问题出现时，`research_cutscene` 的场景源码中缺少：

```gdscript
visible = false
```

Godot 中 `Control.visible` 默认是 `true`。因此场景一启动，全屏过场容器就被显示。

### 2. 黑色遮罩初始透明度为 1

`Dim` 的源码状态为：

```gdscript
color = Color(0, 0, 0, 1)
```

也就是完全不透明黑色。

两者叠加后，启动状态变成：

```text
research_cutscene.visible = true
Dim.alpha = 1.0
```

结果就是：

```text
全屏不透明黑色 UI 覆盖在游戏画面上
→ 开始游戏看起来是黑屏
```

### 3. 为什么主摄像头不是问题

诊断脚本确认启动时实际摄像头状态正常：

```text
scan_camera_current=false
third_camera_current=true
viewport_camera=/root/Node3D/rover/Sojourner/SpringArm3D/Camera3D_3
camera_forward=(0.002341, -0.011691, -0.999929)
environment=true
```

说明第三人称摄像头是当前摄像头，环境存在，rover 也可见。真正遮挡画面的是过场 UI。

---

## 修复方案

### 1. 强制过场容器默认隐藏

在：

```text
CanvasLayer/research_cutscene
```

节点上显式新增：

```gdscript
visible = false
```

修复后的节点源码：

```gdscript
[node name="research_cutscene" type="Control" parent="CanvasLayer" unique_id=1592374412]
visible = false
layout_mode = 3
anchors_preset = 15
anchor_right = 1.0
anchor_bottom = 1.0
grow_horizontal = 2
grow_vertical = 2
mouse_filter = 2
```

### 2. 将遮罩源码默认透明度改为 0

将：

```gdscript
color = Color(0, 0, 0, 1)
```

改为：

```gdscript
color = Color(0, 0, 0, 0)
```

修复后：

```gdscript
[node name="Dim" type="ColorRect" parent="CanvasLayer/research_cutscene" unique_id=2096683413]
layout_mode = 1
anchors_preset = 15
anchor_right = 1.0
anchor_bottom = 1.0
grow_horizontal = 2
grow_vertical = 2
mouse_filter = 2
color = Color(0, 0, 0, 0)
```

这样即使过场容器未来被误设为 visible，遮罩源码默认也不会直接挡住游戏画面。

---

## 为什么不影响 research 黑屏过场

`research_cutscene` 动画的第 0 帧仍会写入：

```text
research_cutscene.visible = true
Dim:color:a = 1.0
```

也就是说，点击 `Research` 后仍然会正常进入黑屏。

当前动画轨道保留不变：

```text
0.0s   过场 visible = true
0.0s   Dim alpha = 1.0
0.3s   开始切入水平摄像头
0.3-0.5s 黑屏淡出
2.7-2.9s 黑屏淡入
2.9s   切回原摄像头
3.1-3.2s 黑屏淡出
3.2s   过场 visible = false
```

因此修复的是：

```text
游戏启动时的错误黑屏
```

不是删除 research 过场中的正常黑屏效果。

---

## 修复前后状态对比

| 状态 | 修复前 | 修复后 |
|---|---|---|
| 启动时 `research_cutscene.visible` | `true` | `false` |
| 启动时 `Dim.alpha` | `1.0` | `0.0` |
| 启动画面 | 被全屏黑色 UI 遮住 | 正常显示第三人称游戏画面 |
| 点击 Research 后 | 黑屏过场正常 | 黑屏过场保持正常 |
| 动画结束后 | 遮罩隐藏 | 遮罩隐藏 |

---

## 验证结果

### 1. 启动状态

修复后启动 `trail_camera.tscn`，检查结果：

```text
startup_overlay_visible=false
startup_dim_alpha=0.0
startup_animation_playing=false
startup_camera=/root/Node3D/rover/Sojourner/SpringArm3D/Camera3D_3
```

说明：

```text
过场 UI 默认隐藏
遮罩透明
AnimationPlayer 未播放
当前摄像头是第三人称主摄像头
```

### 2. 点击 Research 后

触发 research 后：

```text
cutscene_overlay_visible=true
cutscene_initial_dim_alpha=1.0
cutscene_playing=true
```

说明过场开始时仍会正常进入黑屏。

### 3. 动画结束后

```text
ended_overlay_visible=false
ended_dim_alpha=0.0
ended_animation_playing=false
ended_camera=/root/Node3D/rover/Sojourner/SpringArm3D/Camera3D_3
researched=true
tech_point=5
```

说明：

```text
过场正常结束
遮罩恢复透明并隐藏
摄像头恢复正常
research 正常结算
```

---

## 最终结论

开始游戏黑屏的直接原因是：

```text
research_cutscene 全屏 Control 默认可见
Dim 全屏黑色遮罩默认不透明
```

修复方式是：

```text
research_cutscene.visible = false
Dim.color.a = 0
```

过场动画内部的黑屏关键帧不受影响，点击 `Research` 后仍会按原设计播放：

```text
黑屏 → 水平视角 → 扫描 → 黑屏 → 退出
```
